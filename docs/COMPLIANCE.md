# 合规与边界

## 适用范围

职迹采仅用于：

- 本地开发与测试环境；
- 仓库内置合成数据的离线评测；
- 已获得明确授权的教学、演示或研究环境。

它**不适用于真实招聘站点**，不应指向任何真实业务系统，也不应被改造成针对真实站点的采集器。

## 禁止事项

本项目明确不实现、也不应被用于：

- 采集个人简历、联系方式、账号、身份信息或任何个人数据；
- 登录、注册、验证码识别或绕过、风控/反爬绕过、代理池、指纹伪造；
- 批量投递、自动申请、自动联系招聘方或 RPA 操作；
- 绕过站点条款、robots 限制、访问控制或速率限制；
- 对外部域名发起 DNS 解析或 HTTP 请求；
- 分布式大规模采集、消息队列调度或云端任务执行。

## 数据合成

- 64 条基线岗位与所有增量数据均为虚构。
- 公司名使用“示例公司甲（虚构）”“星砂科技（虚构）”等显式合成标记。
- 地点为常见城市与城区的组合，用于验证归一化逻辑；不指向真实办公地址。
- 岗位描述、标签、发布日期均为合成。
- 所有 URL 均为 `http://127.0.0.1:<本地端口>/...`，不包含真实域名。
- 无密钥、令牌、口令、Cookie、私有证书或账户信息。

仓库中的 `not-an-ip`、保留文档 IP 段（如 `2001:db8::/32`）与 IP 字面量仅用于**验证拒绝逻辑**，不会被实际访问；测试在发起网络前断言配置或 URL 守卫抛错。

## 离线保证

1. 默认配置只允许 `http://127.0.0.1:8765`。
2. 配置层要求 `allowed_hosts` 全部为字面 loopback IP；非 IP 主机名直接拒绝，避免隐式 DNS。
3. HTTP 客户端在请求前再次执行 scheme、凭据、主机、端口、allowlist 校验。
4. `requests.Session.trust_env=False`，不读取系统代理环境变量。
5. `allow_redirects=False`，不允许跳转到 allowlist 之外的地址。
6. 响应有字节上限，避免无限下载。
7. 模板与静态资源全部本地内联，无 CDN、远程字体、远程图片或第三方脚本。
8. 测试使用 loopback 临时端口，不依赖外部网络。

## 只读复核台

复核台仅提供 GET：

- `/` 总览
- `/jobs/<job_uid>`
- `/events`
- `/runs`
- `/healthz`

SQLite 以 `mode=ro` 打开，并执行 `PRAGMA query_only=ON`；POST 等写方法返回 405。数据库缺失返回 503，不自动创建空库。

## 安全响应头

mock 站点与复核台均设置：

- `X-Content-Type-Options: nosniff`
- `Content-Security-Policy: default-src 'self'; style-src 'unsafe-inline'; img-src 'self' data:`

页面无内联脚本、无第三方资源。

## 代码与依赖

- 依赖仅 Flask、Jinja2、requests、BeautifulSoup4、PyYAML、pytest。
- 不使用 Playwright、Selenium、浏览器二进制、Node、Docker、Redis、Celery。
- 不引入未使用依赖。
- 仓库不包含任何凭据；也不应从环境变量读取真实凭据。
- 错误消息只包含配置键、路径、loopback URL 与合成岗位 ID，不回显敏感数据。

## 责任边界

使用者必须在运行前确认：

- 目标地址为仓库内置 mock；
- 数据为合成数据；
- 环境已隔离，不会误连生产网络；
- 不将采集结果与任何真实个人或组织关联。

任何超出上述范围的改造与运行由使用者自行承担责任；项目作者不为滥用行为提供支持。

## 检查方式

建议在每次变更后执行：

```bash
make test
make lint-size
```

并人工确认：

- 默认配置仍只含 `127.0.0.1`；
- 场景 JSON 无真实公司/个人信息；
- 模板无远程资源；
- 测试仍包含“非 loopback 拒绝”断言；
- 报告与日志不含敏感字段。
